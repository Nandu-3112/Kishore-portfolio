# kishorepinninti.in

Portfolio of Kishore Pinninti, AI Strategy Consultant at Outskill: sales brain, AI orchestrator.

- `index.html`: the whole site in one file (styles, scripts and the Chaturvir images are built in)
- `images/`: the original Chaturvir campaign images

## Run it locally
Open `index.html` in any browser.

## Host it
Upload `index.html` to the `public_html` folder of your GoDaddy hosting. Or turn on GitHub Pages for this repo (Settings → Pages → deploy from the `main` branch) and point the domain at it.
